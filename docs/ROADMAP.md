# План разработки

## Готово

- Захват Ethernet / IPv4 / TCP на Linux, диагностика и остановка по сигналу.
- Чтение PCAP через тот же цикл. На контрольной записи алерты трёх правил
  ET Open совпали с Suricata 8.0.2.
- Локальный API, ограниченная доставка алертов и отчёты о состоянии сенсора.
- Сквозная проверка на Ethernet-стенде: живые VNC-алерты дошли до браузера
  без перезагрузки. Условия воспроизведения — в [описании стенда](LAB.md).

## Проверки стенда

- [ ] Повторить сквозную проверку с `traffic-gen`.
- [ ] Проверить сетевую конфигурацию после перезагрузки и на зеркалированном канале.
- [ ] Измерить задержку алертов, потери захвата, расход памяти и CPU.
- [ ] На независимых записях измерить ложные срабатывания и пропуски.
  Для наборов данных фиксировать версию, метки и способ отбора.
